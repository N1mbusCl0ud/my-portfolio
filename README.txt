Klowd portfolio (MVC)

index.html        the page structure (HTML)
css/style.css     the look (colors, fonts, layout)
js/model.js       MODEL: your content and data. Edit this to change text, skills, projects, links.
js/view.js        VIEW: draws the data on the page
js/controller.js  CONTROLLER: reacts to scrolling, clicks and the mouse

To view it: open index.html in a browser.
To put it on GitHub Pages: upload everything (keep the css and js folders) to your repository...
